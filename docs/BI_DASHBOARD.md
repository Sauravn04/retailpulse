# Step 5 — BI dashboard: Excel, Tableau, Power BI

Status: built 1 Nov 2026. Excel workbook is generated by
`scripts/export_bi.py` from Gold. Tableau / Power BI are built
by hand following this guide — there is no file to download for
them, the dashboard lives in the BI tool, connected to Postgres.

## 1. Excel (the workbook)

Run:
```
python scripts/export_bi.py
```
It writes `bi/retailpulse_bi.xlsx` and `bi/*.csv`.

Sheets:
- **Dashboard** — headline numbers: total revenue 3,827,746,136,
  mean daily revenue, top category, top store, Champions /
  Hibernating / At Risk counts, customers with no orders,
  quarantined rows. Read this sheet first.
- **Daily_Trend** — 1,462 rows, with a line chart: daily revenue
  and the 7-day rolling average.
- **Monthly_Trend** — 49 rows. Remember: Jan 2024 is a 1-day
  partial month, its MoM is meaningless.
- **Top_Categories** — 30 rows, with a bar chart. Top 5 are
  categories 5, 3, 21, 26, 12, together ~17.7% of revenue.
- **Top_Stores** — 100 rows. Top 5 are stores 9, 72, 48, 4, 67,
  together ~5.2% of revenue.
- **RFM_Segments** — 7 rows, with a bar chart. Largest segment
  on the real data is Hibernating (11,234).
- **RFM_Customers** — 49,751 rows, one per customer who ordered,
  sorted by monetary descending.

Making a pivot in Excel (the skill Amber lists):
1. Open `Daily_Trend`, select all, Insert → PivotTable.
2. Rows: `order_date` grouped by month. Values: Sum of `revenue`.
   That reproduces `Monthly_Trend` — check it matches.
3. Same on `Top_Categories`: Rows `category_id`, Values Sum of
   `revenue`, sort descending. That reproduces the ranking.

## 2. Tableau (free: Tableau Public)

1. Connect → PostgreSQL. Server `127.0.0.1`, port `5432`,
   database `retailpulse`, user `retailpulse_user`.
   (Tableau Public cannot use a live Postgres connection —
   use Extract, or use the `bi/*.csv` files instead.)
2. Drag in these tables/views: `gold.daily_sales`,
   `gold.v_daily_trend`, `gold.v_top_categories`,
   `gold.v_top_stores`, `gold.rfm_customers`.
   Join `rfm_customers` to nothing — it is already one row
   per customer.
3. Build these 4 visuals on one dashboard:
   - Line: `order_date` (x) vs `revenue` and `rolling_7d_revenue`
     (y), from `v_daily_trend`.
   - Bar: `category_id` vs `revenue`, sorted descending,
     from `v_top_categories`.
   - Bar: `store_id` vs `revenue`, top 10 only, from `v_top_stores`.
   - Bar: `segment` vs count of customers, from `rfm_customers`.
4. Add a filter on `order_date` (range) and on `segment`.
5. Check the dashboard total: the sum of revenue on every
   visual must be 3,827,746,136. If it is not, a join is
   duplicating rows — fix the join, not the number.

## 3. Power BI (free: Power BI Desktop)

1. Get Data → PostgreSQL database. Same server / database /
   user as above. Import mode is fine; DirectQuery also works.
2. Import the same 5 tables/views as Tableau.
3. Build the same 4 visuals as Tableau, plus a card visual
   showing total revenue (Sum of `revenue` from `daily_sales`).
4. Add a slicer on `order_date` and a slicer on `segment`.
5. Same check: every visual's revenue total must be
   3,827,746,136.

## Which tool to pick
- Excel first: the workbook is already built, and pivots are
  an Amber must-have. Do this one for sure.
- Then **one** of Tableau or Power BI, not both. Tableau Public
  is the easiest to share as a link; Power BI Desktop is the
  easiest if you already have a Microsoft account. Either one
  satisfies "Tableau and/or Power BI" in the Amber posting.
